# ☕ Cafe Website

A responsive cafe website built using HTML and CSS to showcase menu items, cafe ambiance, and contact details.

## 📌 About

This project is a simple and responsive website for a cafe.  
It is designed with modern layout techniques using HTML and CSS to display:

- Home page with welcome section
- Menu section with items and prices
- About section
- Contact or reservation section

The website is fully responsive and works well on desktops, tablets, and mobile devices.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- (Optional) **JavaScript** for interactive UI
